# Бот онлайн-записи в MAX на n8n с мини-приложением

Запись клиентов к мастерам без звонков: кнопками в чате бота или через мини-приложение внутри MAX. Администратор ведет записи, графики и услуги прямо в боте, напоминания клиентам уходят автоматически. Работает на тестовом стенде (Docker: n8n + PostgreSQL): бот проверен вживую в MAX, мини-приложение — в браузере и эмуляцией запросов.

## Что умеет

- Клиент: услуга → мастер или «Любой мастер» → день и время → имя и телефон → согласие → запись; «Мои записи» и отмена.
- Мини-приложение: те же шаги карточками — услуги с ценой и длительностью, лента дней, сетка свободного времени.
- Администратор: записи на день, запись клиента по телефону, графики мастеров и услуги — кнопками в том же боте.
- Напоминания: раз в 15 минут сценарий находит ближайшие записи и пишет клиенту в MAX, статус доставки сохраняется.
- Защита: подпись вебхука MAX секретом, подпись данных мини-приложения (initData) токеном бота и проверка свежести, повторное нажатие не создает дубль записи, у n8n нет прямого доступа к таблицам — только к функциям SECURITY DEFINER.

## Как устроено

```
MAX ──► webhook booking-dialog ─► guard ─► route ─► функции bot_* ─► PostgreSQL
                                             └─► render ─► ответ кнопками в MAX
Мини-приложение (miniapp/page.html) ─► API n8n (miniapp/api.js, проверка initData) ─► те же функции
Расписание 15 мин ─► booking-reminders ─► напоминания в MAX
```

- `n8n/booking-dialog.json`, `n8n/booking-reminders.json` — сценарии n8n; `n8n/code/` — код узлов отдельными файлами; `n8n/build.js` — сборка сценариев из кода с подстановкой учетных данных.
- `miniapp/page.html` — мини-приложение: один HTML-файл без сборщика, мост `max-web-app.js`; `miniapp/api.js` — проверка подписи и операции API; `miniapp/build.js` — сборка сценария n8n, который отдает страницу и API.
- `sql/` — схема записи, API, хранение и удаление данных, меню администратора, состояние диалога; `verify_*.sql` — проверки миграций.

## Стек

n8n 2.x, PostgreSQL 16, MAX Bot API и MAX Mini Apps, JavaScript без зависимостей, Docker.

## Запуск

1. Применить `sql/050…054` к PostgreSQL, затем `verify_*.sql`; пример справочника — `booking_refdata_example.sql`.
2. `node n8n/build.js --render <папка> --client demo --screen answer`, импортировать сценарии в n8n, создать учетные данные PostgreSQL и MAX.
3. Переменные окружения n8n — по `.env.example`: `DEMO_MAX_WEBHOOK_SECRET`, `DEMO_WEBAPP_KEY`.
4. `node miniapp/build.js <файл.json>`, импортировать, указать адрес страницы в настройках бота.
